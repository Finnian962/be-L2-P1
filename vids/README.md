# vids – opname van de scenario's

Zet hier je korte filmpje (**maximaal 60 seconden**) in, bijvoorbeeld:

```
vids/be-opdracht-02-userstories.mp4
```

## Wat moet er in het filmpje?

Alleen je **browser** filmen (geen code), en de handelingen uit de vier scenario's uitvoeren:

1. **US01 scenario_01** – Overzicht leveranciers → box-icoon bij Venco → Geleverde producten met
   aantal in magazijn en laatste levering, gesorteerd op aantal aflopend.
2. **US01 scenario_02** – box-icoon bij Quality Street → melding *"Dit bedrijf heeft tot nu toe geen
   producten geleverd aan Jamin"* → na 3 seconden terug naar Overzicht leveranciers.
3. **US02 scenario_01** – Venco → Mintnopjes → plus-icoon → `29 mei 2024` en `25` invullen →
   Sla op → terug op Geleverde producten met gewijzigd aantal en laatste levering.
4. **US02 scenario_02** – Basset → Winegums → plus-icoon → `30` en de datum van vandaag → Sla op →
   melding *"Het product Winegums van de leverancier Basset wordt niet meer geproduceerd"* →
   na 4 seconden door naar Geleverde producten van Basset.

Laat in hetzelfde filmpje ook even je **create-script** zien (tabellen + relaties + data), bijvoorbeeld
door `db/create_script_Jamin.sql` kort te openen en de `SHOW TABLES;`/`SELECT *;` uitvoering te tonen.
